# modify-enc-str

외부 암호화/복호화 스크립트(`--cipher`)와 연동하여 평문 문자열을 암호화한 후, 대상 디렉토리 내 설정 파일들에서 이전 암호문(또는 평문)을 검색하여 새로운 암호문으로 일괄 안전하게 치환하는 보안 설정 파일 일괄 갱신 도구입니다.

---

## ✨ 주요 특징

- **사용자 정의 Cipher 스크립트 연동**: 암호화 함수/스크립트(`--cipher`)를 실행 인자로 받아 평문을 암호문으로 자동 변환합니다.
- **대화형 3단계 안전 확인(Interactive Confirmation)**:
  - 1단계: 변경 전/후의 평문과 암호문 결과를 화면에 표시하고 사용자 승인(`Y`: 진행, `N`: 중단, `R`: 재입력)
  - 2단계: 대상 파일 검색 결과 및 일치 행 목록을 출력한 후 실제 치환 여부 재확인
  - 3단계: 일괄 치환 후 변경 결과 검증 출력
- **정규식 특수문자 자동 이스케이프**: 암호문에 포함될 수 있는 슬래시(`/`) 등의 특수 기호를 `sed` 구문에 맞게 자동으로 정규화 처리합니다.
- **다중 파일 패턴 지원**: 쉼표(`,`)로 구분하여 여러 파일명 패턴을 동시에 지정할 수 있습니다.
- **지능형 Bash 자동완성**: 디렉토리, 스크립트 파일 및 옵션 자동완성을 완벽하게 지원합니다.

## ⚙️ 파라미터 명세

| 파라미터 | 단축 옵션 | 필수 여부 | 기본값 | 설명 |
| :--- | :---: | :---: | :---: | :--- |
| `--dir <디렉토리>` | `-d` | **필수** | - | 검색 및 치환 대상 디렉토리 경로 |
| `--files <패턴목록>` | `-f` | **필수** | - | 검색할 파일 패턴 (쉼표 구분 다중 지정 가능, 예: `*.properties,*.yml`) |
| `--old <기존평문>` | `-o` | **필수** | - | 변경 전 기존 평문 문자열 |
| `--new <신규평문>` | `-n` | **필수** | - | 변경할 신규 평문 문자열 |
| `--cipher <스크립트>` | `-c` | **필수** | - | 문자열을 인자로 받아 암호문을 출력하는 스크립트/명령어 |
| `--help` | `-h` | 선택 | - | 도움말 메시지를 표시합니다. |

## 🚀 사용 예시

### 1. 설정 파일의 암호화된 비밀번호 일괄 교체
```bash
modify-enc-str \
  -d /opt/services/config \
  -f "application-*.yml,config.properties" \
  -o "OldPassword123!" \
  -n "NewSecretPass456!" \
  -c "/usr/local/bin/my-encryptor"
```

## 💻 설치 안내

저장소의 `utils/scriptctl` 도구를 사용하여 개인 실행 경로(`~/bin`) 또는 시스템 전역 경로에 간편하게 설치할 수 있습니다. 설치 시 Bash 자동완성 스크립트도 시스템 표준 경로에 자동으로 등록됩니다.

```bash
# 개인 환경 설치 (~/bin, 사용자 자동완성 등록) 
../scriptctl/scriptctl install --script ./modify-enc-str --target local

# 시스템 전역 설치 (/usr/local/bin, /usr/share/bash-completion/completions/ 등록) 
../scriptctl/scriptctl install --script ./modify-enc-str --target global
```
