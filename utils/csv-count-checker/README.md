# csv-count-checker

CSV 또는 특정 구분자(Delimiter)로 이루어진 대용량 텍스트 파일에서 각 행(Line)의 컬럼(필드) 개수가 예상한 수치와 일치하는지 전수 검증하고, 불일치하는 행을 별도 기록 파일에 실시간 저장하는 데이터 정합성 검증 도구입니다.

---

## ✨ 주요 특징

- **정밀한 컬럼 개수 검증**: 지정한 구분자(`,`, `|`, `\t` 등)를 기준으로 각 행의 필드 수가 지정한 값과 일치하는지 전수 검사합니다.
- **불일치 행 자동 기록**: 컬럼 수가 일치하지 않는 비정상 행을 줄 번호, 실제 컬럼 수와 함께 `<파일명>.checkcount-<타임스탬프>` 파일에 즉시 기록합니다.
- **최대 라인 제한(`-n`) 지원**: 전체 파일 검증 외에도 앞부분 특정 라인 수만 샘플링하여 검증할 수 있습니다.
- **실시간 진척도 및 소요 시간 계산**: 처리 라인 수, 진행률, 시작/종료 시간 및 경과 시간(시/분/초)을 상세히 출력합니다.
- **지능형 Bash 자동완성**: 파일 경로, 구분자 후보 및 옵션 자동완성을 지원합니다.

---

## ⚙️ 파라미터 명세

| 파라미터 | 단축 옵션 | 필수 여부 | 기본값 | 설명 |
| :--- | :---: | :---: | :---: | :--- |
| `--file <파일경로>` | `-f` | **필수** | - | 검증할 원본 CSV/텍스트 파일 경로 |
| `--delim <구분자>` | `-d` | **필수** | - | 데이터 필드 구분자 (예: `,`, `\|`, `\t`) |
| `--count <개수>` | `-c` | **필수** | - | 정상 행의 예상 데이터 컬럼(필드) 수 |
| `--number <라인수>` | `-n` | 선택 | `-1` (전체) | 검사할 최대 라인 수 |
| `--help` | `-h` | 선택 | - | 도움말 메시지를 표시합니다. |

---

## 🚀 사용 예시

### 1. 쉼표(`,`) 기준 10개 컬럼을 가진 CSV 파일 전수 검증
```bash
csv-count-checker -f ./dataset.csv -d "," -c 10
```

### 2. 파이프(`|`) 구분자 파일의 상위 50,000행만 검증
```bash
csv-count-checker -f ./raw_data.txt -d "|" -c 7 -n 50000
```

## 💻 설치 안내

저장소의 `utils/scriptctl` 도구를 사용하여 개인 실행 경로(`~/bin`) 또는 시스템 전역 경로에 간편하게 설치할 수 있습니다. 설치 시 Bash 자동완성 스크립트도 시스템 표준 경로에 자동으로 등록됩니다.

```bash
# 개인 환경 설치 (~/bin, 사용자 자동완성 등록) 
../scriptctl/scriptctl install --script ./csv-count-checker --target local

# 시스템 전역 설치 (/usr/local/bin, /usr/share/bash-completion/completions/ 등록) 
../scriptctl/scriptctl install --script ./csv-count-checker --target global
```
