# autotail

지정한 대상 파일(로그 등)이 아직 생성되지 않은 상태일 때 생성을 대기(Polling)하다가, 파일이 생성되는 즉시 자동으로 감지하여 `tail -f`를 실행하는 자동 로그 모니터링 도구입니다.

---

## ✨ 주요 특징

- **파일 생성 감지 대기(Polling)**: 백그라운드 프로세스나 데몬이 시작되면서 아직 로그 파일을 생성하기 전이라도, 대기 카운트를 표시하며 파일 생성을 주기적으로 확인합니다.
- **실시간 추적 자동 전환**: 파일 생성이 확인되면 즉시 지정한 초기 라인 수(`-n`)와 함께 `tail -f`로 전환하여 끊김 없는 로그 모니터링을 시작합니다.
- **초기 출력 라인 수 조절**: 기본 10줄 외에 원하는 줄 수(`-n, --lines`)를 자유롭게 지정할 수 있습니다.
- **지능형 Bash 자동완성**: 파일 경로 및 옵션, 주요 라인 수(10, 20, 50, 100 등) 자동완성을 지원합니다.

---

## ⚙️ 파라미터 명세

| 파라미터 | 단축 옵션 | 필수 여부 | 기본값 | 설명 |
| :--- | :---: | :---: | :---: | :--- |
| `--file <파일경로>` | `-f` | **필수** | - | 모니터링할 대상 파일 경로 |
| `--lines <라인수>` | `-n` | 선택 | `10` | `tail` 시작 시 표시할 이전 라인 수 |
| `--help` | `-h` | 선택 | - | 도움말 메시지를 표시합니다. |

---

## 🚀 사용 예시

### 1. 로그 파일 생성 대기 및 실시간 모니터링
```bash
autotail -f /opt/logs/application.log
```

### 2. 파일 생성 즉시 최근 100줄 출력하며 모니터링
```bash
autotail -f ./server.out -n 100
```

---

## 💻 설치 안내

저장소의 `utils/scriptctl` 도구를 사용하여 개인 실행 경로(`~/bin`) 또는 시스템 전역 경로에 간편하게 설치할 수 있습니다. 설치 시 Bash 자동완성 스크립트도 시스템 표준 경로에 자동으로 등록됩니다.

```bash
# 개인 환경 설치 (~/bin, 사용자 자동완성 등록) 
../scriptctl/scriptctl install --script ./autotail --target local

# 시스템 전역 설치 (/usr/local/bin, /usr/share/bash-completion/completions/ 등록) 
../scriptctl/scriptctl install --script ./autotail --target global
```
