# ssh-con-gen

원격 접속 정보(계정, 비밀번호, 호스트, 포트, 타이틀)를 인자로 받아, `sshpass`와 `ssh`를 통해 원격 서버로 대화형 자동 로그인을 수행하는 독립 실행형 쉘 스크립트를 생성해 주는 접속 스크립트 생성 도구입니다.

---

## ✨ 주요 특징

- **원격 SSH 자동 로그인 래퍼 스크립트 생성**: 비밀번호 입력 과정을 `sshpass`로 자동화한 원격 접속 쉘 스크립트를 즉시 생성합니다.
- **실행 권한 자동 부여**: 생성된 접속 스크립트에 실행 권한(`chmod +x`)을 자동으로 부여하여 즉시 실행 가능합니다.
- **터미널 타이틀 자동 지정**: 접속 시 터미널 창 또는 탭의 타이틀(`-title`)을 설정하는 코드가 자동으로 포함됩니다.
- **특수문자 비밀번호 안전 가이드**: 비밀번호에 느낌표(`!`) 등 쉘 특수문자가 포함된 경우 작은따옴표(`'...'`)로 안전하게 감싸서 전달할 수 있습니다.
- **지능형 Bash 자동완성**: 파라미터 옵션 자동완성을 완벽하게 지원합니다.

---

## ⚙️ 파라미터 명세

| 파라미터 | 필수 여부 | 설명 |
| :--- | :---: | :--- |
| `-user <계정명>` | **필수** | 원격 SSH 접속 계정 |
| `-pwd <비밀번호>` | **필수** | 원격 SSH 접속 비밀번호 (특수문자 포함 시 `'...'` 권장) |
| `-host <호스트>` | **필수** | 원격 서버 IP 주소 또는 도메인 |
| `-port <포트>` | **필수** | SSH 포트 번호 (기본 22 등) |
| `-title <제목>` | **필수** | 접속 쉘 및 터미널 탭에 표시될 타이틀 |
| `-file <출력파일명>` | **필수** | 생성할 접속 스크립트 파일명 |

---

## 🚀 사용 예시

### 1. 개발 서버 원격 접속 스크립트 생성
```bash
ssh-con-gen \
  -user devuser \
  -pwd 'SecretPass123!' \
  -host 192.168.1.100 \
  -port 22 \
  -title "DEV-Server-01" \
  -file connect-dev.sh
```

### 2. 생성된 스크립트로 원격 접속 실행
```bash
./connect-dev.sh
```

## 💻 설치 안내

저장소의 `utils/scriptctl` 도구를 사용하여 개인 실행 경로(`~/bin`) 또는 시스템 전역 경로에 간편하게 설치할 수 있습니다. 설치 시 Bash 자동완성 스크립트도 시스템 표준 경로에 자동으로 등록됩니다.

```bash
# 개인 환경 설치 (~/bin, 사용자 자동완성 등록) 
../scriptctl/scriptctl install --script ./ssh-con-gen --target local

# 시스템 전역 설치 (/usr/local/bin, /usr/share/bash-completion/completions/ 등록) 
../scriptctl/scriptctl install --script ./ssh-con-gen --target global
```
