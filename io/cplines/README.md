# ✂️ cplines

대용량 텍스트 또는 로그 파일에서 지정된 시작 행 번호(`--linenumber`)부터 원하는 행 개수(`--count`)만큼 라인을 정확하게 슬라이싱하여 대상 파일로 복사하고, 실시간 진행률 및 처리 소요 시간을 시각적으로 출력하는 라인 슬라이싱 CLI 도구입니다.

---

## ✨ 주요 특징

1. **지정된 행 범위 정밀 슬라이싱**
   * 대용량 데이터 파일에서 특정 시작 행 번호(`-l`)와 복사할 행 개수(`-c`)를 지정하여 원하는 구간의 데이터만 추출합니다.
2. **실시간 점(dot) 프로그레스 바 표시**
   * 데이터 읽기 진행 상황을 터미널에 실시간으로 표시하여 대용량 작업 중에도 현재 진행 상태를 명확히 파악할 수 있습니다.
3. **정밀 소요 시간 통계 (`timestamp-to-hms`)**
   * 작업 시작/종료 일시 및 실제 추출에 소요된 총 경과 시간(시/분/초)을 자동으로 계산하여 출력합니다.
4. **대상 파일 보호 (덮어쓰기 확인)**
   * 대상 파일이 이미 존재하는 경우, 사용자에게 덮어쓰기 확인(`Y/N`) 프롬프트를 표시하여 실수로 인한 데이터 유실을 방지합니다.
5. **지능형 Bash 자동 완성 (`cplines.completion`)**
   * 옵션 및 파일 경로 자동 완성을 제공합니다.

---

## ⚙️ 파라미터 명세

```bash
cplines -s <소스파일> -d <대상파일> -l <시작행번호> -c <복사할행개수>
```

| 옵션 | 단축형 | 필수 여부 | 설명 |
| :--- | :---: | :---: | :--- |
| `--src <file>` | `-s` | **필수** | 원본 파일 경로 |
| `--dst <file>` | `-d` | **필수** | 추출된 데이터가 저장될 대상 파일 경로 |
| `--linenumber <num>` | `-l` | **필수** | 복사를 시작할 라인 번호 (1부터 시작하는 양의 정수) |
| `--count <num>` | `-c` | **필수** | 복사할 총 라인 개수 (양의 정수) |
| `--help` | `-h` | 선택 | 도움말 메시지 출력 및 종료 |

---

## 🚀 사용 예시

```bash
# 1) 100번째 줄부터 500줄을 추출하여 new_data.log로 복사
./cplines -s big_access.log -d new_data.log -l 100 -c 500

# 2) 대용량 CSV 파일의 10,001번째 레코드부터 1,000개 샘플링
./cplines --src dataset.csv --dst sample.csv --linenumber 10001 --count 1000
```

## 💻 설치 안내

저장소의 `utils/scriptctl` 도구를 사용하여 개인 실행 경로(`~/bin`) 또는 시스템 전역 경로에 간편하게 설치할 수 있습니다. 설치 시 Bash 자동완성 스크립트도 시스템 표준 경로에 자동으로 등록됩니다.

```bash
# 개인 환경 설치 (~/bin, 사용자 자동완성 등록)
../../utils/scriptctl/scriptctl install --script ./cplines --target local

# 시스템 전역 설치 (/usr/local/bin, /usr/share/bash-completion/completions/ 등록)
../../utils/scriptctl/scriptctl install --script ./cplines --target global
```
