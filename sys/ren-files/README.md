# ren-files

대상 디렉토리 내의 파일명들을 `sed` 확장 정규표현식(ERE) 그룹 캡처 및 후방 참조(`\1`, `\2`) 패턴을 이용하여 일괄 변경(배치 리네이밍)하는 파일명 일괄 변경 도구입니다.

---

## ✨ 주요 특징

- **정규식 기반 대량 파일명 변경**: `sed -r` 정규표현식을 활용하여 특정 패턴에 일치하는 파일명을 원하는 구조로 변환합니다.
- **그룹 캡처 및 재배치**: 정규식 괄호(`(...)`)를 통한 캡처 그룹과 후방 참조(`\1`, `\2` 등)를 완벽하게 지원합니다.
- **안전 확인 모드**: 기본적으로 `mv -i`를 통해 기존 파일이 덮어쓰여지는 경우 확인을 거치며, `-f` 지정 시 강제 치환합니다.
- **지능형 Bash 자동완성**: 디렉토리 경로 및 파라미터 옵션 자동완성을 지원합니다.

---

## ⚙️ 파라미터 명세

| 파라미터 | 필수 여부 | 설명 |
| :--- | :---: | :--- |
| `-d <디렉토리>` | **필수** | 대상 파일들이 위치한 디렉토리 경로 |
| `-i <입력정규식>` | **필수** | 매칭할 파일명 `sed` 정규표현식 패턴 |
| `-o <출력패턴>` | **필수** | 변경할 파일명 출력 패턴 (후방 참조 `\1`, `\2` 사용 가능) |
| `-f` | 선택 | 기존 동일 파일명이 존재할 경우 확인 없이 강제 덮어쓰기 (`mv -f`) |
| `-h, --help` | 선택 | 도움말 메시지를 표시합니다. |

---

## 🚀 사용 예시

### 1. 파일명 앞뒤 토큰 순서 변경
```bash
# 원본: a-b.txt, a-c.txt, b-c.txt
ren-files -d . -i '(a)-(.+)' -o '\2-\1'
# 결과: b-a.txt, c-a.txt, b-c.txt
```

### 2. 특정 접두사 일괄 치환
```bash
ren-files -d /data/logs -i '^(error)_(.*)' -o 'warn_\2'
```

## 💻 설치 안내

저장소의 `utils/scriptctl` 도구를 사용하여 개인 실행 경로(`~/bin`) 또는 시스템 전역 경로에 간편하게 설치할 수 있습니다. 설치 시 Bash 자동완성 스크립트도 시스템 표준 경로에 자동으로 등록됩니다.

```bash
# 개인 환경 설치 (~/bin, 사용자 자동완성 등록) 
../../utils/scriptctl/scriptctl install --script ./ren-files --target local

# 시스템 전역 설치 (/usr/local/bin, /usr/share/bash-completion/completions/ 등록) 
../../utils/scriptctl/scriptctl install --script ./ren-files --target global
```
