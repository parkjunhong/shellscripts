# disk-size

대상 디렉토리 또는 파일의 디스크 점유 용량을 고속 일괄(Batch) 처리 파이프라인으로 측정하고, 파일(`[f]`)과 디렉토리(`[d]`) 구분 및 크기 순 정렬(오름차순/내림차순)과 재귀 탐색을 제공하는 고성능 디스크 사용량 분석 도구입니다.

---

## ✨ 주요 특징

- **초고속 일괄 스트리밍 아키텍처 (성능 최적화)**:
  - 파일별 개별 프로세스 포크(`du`, `awk`) 및 임시 파일(`/tmp`) 생성을 전면 제거하고, `find` + `xargs -0 du -sh` + `sort -h` 단일 스트림 파이프라인으로 리팩토링하여 대용량 디렉토리에서도 **수십 배 이상의 비약적인 성능 향상**을 달성했습니다.
- **사람이 읽기 쉬운 규격화된 크기 표시**: 바이트 단위를 `4.0K`, `12.5M`, `1.5G` 등 직관적인 단위로 자동 서식화하여 출력합니다.
- **다양한 정렬 모드 지원**:
  - `--sort-asc`: 용량 기준 오름차순(작은 순서부터) 정렬
  - `--sort-desc`: 용량 기준 내림차순(큰 순서부터) 정렬
  - 미지정: 탐색 순서 그대로 출력
- **재귀 탐색 지원 (`--recursive`)**: 지정 시 하위 모든 디렉토리 및 파일까지 포함하여 점유 용량을 전수 조사합니다.
- **지능형 Bash 자동완성**: 디렉토리 경로 및 정렬/재귀 옵션 자동완성을 완벽하게 지원합니다.

---

## ⚙️ 파라미터 명세

| 파라미터 | 필수 여부 | 기본값 | 설명 |
| :--- | :---: | :---: | :--- |
| `<directory>` | 선택 | `.` (현재 디렉토리) | 탐색 대상 디렉토리 또는 파일 경로 |
| `--sort-asc` | 선택 | - | 파일 크기 기준 오름차순(Ascending) 정렬 |
| `--sort-desc` | 선택 | - | 파일 크기 기준 내림차순(Descending) 정렬 |
| `--recursive` | 선택 | 비활성 | 하위 디렉토리 재귀적(Recursive) 탐색 활성화 |
| `--help` | 선택 | - | 도움말 메시지를 표시합니다. |

---

## 🚀 사용 예시

### 1. 현재 디렉토리 직하위 항목 크기 내림차순 정렬
```bash
disk-size --sort-desc .
```

### 2. 특정 디렉토리 하위 모든 파일/폴더 재귀 탐색 후 용량순 정렬
```bash
disk-size --sort-desc --recursive /var/log
```

## 💻 설치 안내

저장소의 `utils/scriptctl` 도구를 사용하여 개인 실행 경로(`~/bin`) 또는 시스템 전역 경로에 간편하게 설치할 수 있습니다. 설치 시 Bash 자동완성 스크립트도 시스템 표준 경로에 자동으로 등록됩니다.

```bash
# 개인 환경 설치 (~/bin, 사용자 자동완성 등록) 
../../utils/scriptctl/scriptctl install --script ./disk-size --target local

# 시스템 전역 설치 (/usr/local/bin, /usr/share/bash-completion/completions/ 등록) 
../../utils/scriptctl/scriptctl install --script ./disk-size --target global
```
