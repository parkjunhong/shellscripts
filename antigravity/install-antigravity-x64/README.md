# 🚀 install-antigravity-x64

Google Antigravity 공식 저장소에서 사용 가능한 **Antigravity Core/CLI x64(2.x 이상)** 버전 목록을 원격 조회하고, 사용자가 선택한 버전의 패키지를 다운로드하여 시스템(`/opt/antigravity`)에 자동 설치 및 환경 구성을 수행하는 CLI 설치 도구입니다.

---

## ✨ 주요 특징

1. **원격 저장소 기반 2.x+ x64 버전 동적 조회 및 대화형 선택**
   * Google Antigravity 공식 릴리스 저장소에서 메타데이터를 파싱하여 Linux x64 호환 2.x 이상 버전 목록을 가져옵니다.
   * `--version` 옵션을 생략하면 설치 가능한 버전 목록을 출력하고 대화형으로 설치 버전을 선택할 수 있습니다.
2. **원스톱 시스템 환경 구성**
   * `/opt/antigravity` 경로에 바이너리를 배치하고, 전역 실행 경로인 `/usr/local/bin/agy` 및 `/usr/local/bin/antigravity` 심볼릭 링크를 생성합니다.
   * 데스크톱 바로가기(`antigravity.desktop`) 및 시스템 아이콘을 자동 등록하여 GUI/CLI 환경 모두에서 즉시 접근할 수 있도록 구성합니다.
   * 샌드박스 실행 권한(`chrome-sandbox` 등)을 사전에 검증하고 설정합니다.
3. **구버전 정리 및 임시 파일 안전 회수 (Trap)**
   * 설치 도중 중단되거나 오류가 발생하더라도 `trap` 기반 임시 다운로드 파일 자동 정리 로직이 동작하여 시스템 찌꺼기를 남기지 않습니다.
4. **시뮬레이션 모드 (`--dry-run`) 지원**
   * 실제 시스템 파일 변경 없이 다운로드 URL, 설치 경로 및 실행될 단계들을 사전 검증할 수 있습니다.

---

## ⚙️ 파라미터 명세

| 옵션 | 필수 여부 | 설명 |
| :--- | :---: | :--- |
| `--version <버전>` | 선택 | 원격 저장소에서 필터링할 버전 식별자 (예: `2`, `2.24`, `2.24.0`). 생략 시 전체 버전 목록 출력 후 대화형 선택 |
| `--dry-run` | 선택 | 실제 다운로드 및 시스템 설치를 진행하지 않고 실행 계획만 출력 |
| `--help` | 선택 | 도움말 출력 |

> **주의**: 단축 옵션(`-v`, `-d`, `-h` 등)은 지원하지 않으며 정규 롱 옵션만 지원합니다.

---

## 🚀 사용 예시

```bash
# 1) 설치 가능한 x64 버전 목록을 대화형으로 확인하고 선택하여 설치
./install-antigravity-x64

# 2) 특정 버전(예: 2.24)을 지정하여 설치
./install-antigravity-x64 --version 2.24

# 3) 실제 설치 없이 시뮬레이션 모드로 확인
./install-antigravity-x64 --version 2.24.0 --dry-run
```
