# 📥 git-pull

현재 작업 중인 브랜치 또는 지정한 대상 브랜치의 최신 변경사항을 원격 저장소로부터 안전하게 가져오는(`git pull`) Git 자동화 CLI 도구입니다. 대상 브랜치가 현재 브랜치와 다를 경우, **대상 브랜치로 전환(`git switch`) &rarr; 최신화(`git pull`) &rarr; 원래 작업 브랜치로 자동 복귀(`git switch`)** 파이프라인을 일괄 수행합니다.

> [!NOTE]
> `git-pull`은 유효한 Git 저장소 디렉토리 내부에서만 동작할 수 있습니다. 비 Git 디렉토리에서 실행하거나 자동완성(`<TAB>`) 시에는 동작이 안전하게 차단됩니다.

---

## ✨ 주요 특징

1. **현재 브랜치 자동 감지 및 스마트 분기**
   - 브랜치 인자를 생략할 경우 현재 체크아웃되어 있는 브랜치를 자동으로 감지하여 `git pull`을 수행합니다.
2. **원래 작업 브랜치 안전 자동 복귀 (Trap Handler)**
   - 다른 브랜치명을 인자로 지정한 경우, 해당 브랜치로 전환하여 최신 코드를 pull한 뒤 **원래 머물던 작업 브랜치로 자동 복귀**합니다.
   - pull 수행 중 네트워크 장애, 충돌 또는 `Ctrl+C` 인터럽트가 발생하더라도 Trap 핸들러를 통해 원래 브랜치로 안전하게 복귀하여 작업 흐름을 유지합니다.
3. **사전 무결성 점검 (Pre-flight Validation)**
   - **Git 저장소 환경 점검**: Git 작업 트리가 없는 디렉토리에서 실행 시 즉시 중단합니다.
   - **로컬 미커밋 변경사항 보호**: 대상 브랜치로의 전환이 필요한 경우, 작업 트리에 커밋되지 않은 수정사항이 남아 있으면 브랜치 이동 충돌 및 코드 유실을 방지하기 위해 작업을 사전에 차단합니다.
   - **브랜치 존재 여부 검증**: 지정한 브랜치가 로컬 또는 원격 저장소에 존재하는지 사전에 확인합니다.
4. **Bash 자동완성 지원**
   - `git-pull <TAB>` 입력 시 현재 Git 저장소에 존재하는 로컬 및 원격 브랜치 목록을 실시간으로 분석하여 자동완성을 제공합니다.

---

## ⚙️ 파라미터 명세

| 파라미터 | 필수 여부 | 기본값 | 설명 |
| :--- | :---: | :---: | :--- |
| `<branch>` | 선택 | **현재 작업 브랜치** | 최신화(pull)를 수행할 대상 브랜치 이름 |
| `--help` | 선택 | - | 도움말 및 사용법 화면 출력 |

---

## 🚀 사용 예시

```bash
# 1) 현재 머물고 있는 브랜치 최신화 (인자 생략)
git-pull

# 2) 다른 브랜치(예: develop)를 최신화한 후 원래 작업 브랜치로 자동 복귀
git-pull develop

# 3) main 브랜치를 최신화한 후 현재 기능 브랜치(feature/xxx)로 복귀
git-pull main

# 4) 사용법 및 옵션 안내 조회
git-pull --help
```

## 💻 설치 안내

저장소의 `utils/scriptctl` 도구를 사용하여 개인 실행 경로(`~/bin`) 또는 시스템 전역 경로에 간편하게 설치할 수 있습니다. 설치 시 Bash 자동완성 스크립트도 시스템 표준 경로에 자동으로 등록됩니다.

```bash
# 개인 환경 설치 (~/bin, 사용자 자동완성 등록)
../../utils/scriptctl/scriptctl install --script ./git-pull --target local

# 시스템 전역 설치 (/usr/local/bin, /usr/share/bash-completion/completions/ 등록)
../../utils/scriptctl/scriptctl install --script ./git-pull --target global
```
